税镜 · 生产部署安全前置与上线分步清单

上线＝把系统从「本地随便跑」变成「公网正式服务」之前，必须先堵住的几道门。本清单分两层：代码侧（已替你做） 与 你/平台侧（需你操作）。

一、概念：什么是"安全前置项"

公网可达的 tax.hgtcs.com 任何人都能直接打你的 API。开发期为省事留的"方便后门"，上线即风险。主要有三类：

  • 弱口令 / 空口令：运营后台、定时任务令牌若用默认值，等于把钥匙挂公网。
  • 无来源限制：仅靠静态 token 的高危接口（运营后台、定时触发）任何人带对 token 就能调。
  • 密钥缺失：微信 AppSecret、订阅模板、企微参数未配置，功能失效或暴露默认值。

二、代码侧（已做，你不用动）已完成·本地验证全过

  • token 生产强制：APP_ENV=production 且未设强 token 时，服务启动即 sys.exit(1) 拒绝运行（杜绝弱口令上线）。
  • 来源 IP 白名单网关：_gate_sensitive() 拦截 /api/admin/ 与 /api/cron/，默认仅本机；支持反代下读真实 IP。
  • admin_authorized 空口令防护：空 token 直接拒绝，防"空==空"绕过。
  • 零依赖 .env 加载：密钥不硬编码进源码，附 .env.example 模板。

架构提醒：生产经 nginx 反代，后端看到的来源是 nginx 本机。要让 IP 白名单真正生效，必须配 TRUST_PROXY=1 + nginx 覆盖式注入 X-Forwarded-For；更稳的做法是在 nginx 层直接对 /api/admin/ 做 allow/deny（见第 5 步）。

三、你需要做的（分步勾选）

第 1 步 · 生成两个强随机令牌
在你的电脑或服务器上运行，各生成一次，复制保存好： 
# 生成 ADMIN_TOKEN 与 CRON_TOKEN（各跑一次）
python -c "import secrets; print(secrets.token_hex(24))"
第 2 步 · 微信公众平台配置（mp.weixin.qq.com）
登录小程序后台 → 开发 → 开发设置 → 服务器域名，request 合法域名加 https://tax.hgtcs.com；
开发设置里复制 AppSecret（即 WX_APPSECRET，AppID 已是 wx1dbe0f380c108b9f）；
功能 → 订阅消息 → 一次性订阅，申请"征期/申报提醒"类模板，拿到 模板 ID（即 WX_SUBSCRIBE_TMPL_ID）。
第 3 步 · 企微客服参数（可选，不配则前端降级提示）
企微管理后台拿 WX_CORPID，生成客服二维码图，配置 WX_KEFU_QR 图片地址。
第 4 步 · 生产服务器部署（124.222.33.233）
① 把本地代码同步到 /opt/suijing（server.py / miniprogram / admin.html / org.html / db / scripts / .env）；
② 在服务器建 /opt/suijing/.env，填入： 
APP_ENV=production
ADMIN_TOKEN=# 第1步生成
CRON_TOKEN=# 第1步生成
WX_APPSECRET=# 第2步
WX_SUBSCRIBE_TMPL_ID=# 第2步模板ID
ADMIN_ALLOWED_IPS=127.0.0.1,你的办公出口IP
TRUST_PROXY=1
LLM_API_KEY=# 大模型KEY（不配则AI问答走规则兜底）
WX_CORPID=# 第3步，可选
WX_KEFU_QR=# 第3步，可选
③ systemd 已支持自动读 .env，无需改 service 文件；④ systemctl daemon-reload && systemctl restart suijing。
第 5 步 · nginx 配置（关键硬防线）
在反代 server 块里：对运营接口做 IP 限制，并覆盖式注入 X-Forwarded-For（保证后端拿到真实来源）： 
location /api/admin/ {
    allow 127.0.0.1;
    allow 你的办公出口IP;
    deny all;
    proxy_pass http://127.0.0.1:8090;
}
location / {
    proxy_pass http://127.0.0.1:8090;
    # 覆盖式（不是 $proxy_add_x_forwarded_for）才可信：
    proxy_set_header X-Forwarded-For $remote_addr;
    proxy_set_header Host $host;
}
改完 nginx -t && systemctl reload nginx。
第 6 步 · 验证上线
① 公网打 https://tax.hgtcs.com/api/admin/community/list（非白名单 IP / 无 token → 返回 forbidden 或 403）；
② 小程序真机预览：问答 / 同行问 / 征期日历；
③ 征期页点"开启提醒"→ 微信授权 → 查生产库 user_subscription 表应有 active 记录；
④ 加 systemd timer 每日调 /api/cron/push-deadlines（带 X-Cron-Token 或 X-Admin-Token）。
⚠️ 上线前铁律：第 2 步合法域名、第 4 步强 token、第 5 步 nginx allow/deny —— 缺一不可。少任何一项都不算"安全前置已补齐"，先别开放公网注册。
